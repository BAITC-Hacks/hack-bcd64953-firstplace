# AI Sana Challenge Hub

Проект временно упрощён для поэтапной разработки.

## Структура

- `frontend/` — интерфейс на чистых HTML, CSS и JavaScript.
- `backend/` — Python 3.14.7 / FastAPI REST API с Supabase Auth, PostgreSQL и Storage.

## Запуск frontend

Откройте `frontend/index.html` через расширение Live Server в VS Code.

Обычный адрес:

```text
http://127.0.0.1:5500/frontend/
```

Для просмотра статического frontend Node.js, React, Python и база данных не требуются.

## Backend

Запуск и настройка: [backend/README.md](backend/README.md). Сервер работает отдельно на порту
8000. Текущий статический frontend ещё не подключён к API; его дизайн и файлы не изменены.
