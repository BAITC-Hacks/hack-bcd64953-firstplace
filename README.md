# AI Sana Challenge Hub

Проект временно упрощён для поэтапной разработки.

## Структура

- `frontend/` — интерфейс на чистых HTML, CSS и JavaScript.
- `backend/` — пустая заготовка для будущего подключения Supabase и PostgreSQL.

## Запуск frontend

Откройте `frontend/index.html` через расширение Live Server в VS Code.

Обычный адрес:

```text
http://127.0.0.1:5500/frontend/
```

Node.js, React, Python и база данных на текущем этапе не требуются.
